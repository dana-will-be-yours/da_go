# DA GO TRPG 團務資料庫

這個 repository 提供 GitHub Pages 可直接執行的靜態網頁。

## 本機開啟

直接開啟 `index.html`，或使用 PowerShell 啟動簡易伺服器：

```powershell
cd "C:\Users\sun\Documents\New project\da_go"
python -m http.server 8080
```

瀏覽器開啟：

```text
http://localhost:8080
```

## GitHub Pages

推送到 `main` 後，GitHub Actions 會部署靜態頁面。若 repository 第一次啟用 Pages，請在 GitHub repository 的 `Settings > Pages` 選擇 GitHub Actions 來源。

預期網址：

```text
https://dana-will-be-yours.github.io/da_go/
```
